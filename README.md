# superpet-drafts

Публичные черновики макетов SUPERPET для ревью коллегами (через GitHub Pages,
ссылка открывается без аккаунта Claude).

Каждый макет — самодостаточный HTML-файл (шрифты/картинки встроены), в своей
подпапке.

## Текущие черновики

- `meal-plan/` — квиз-подборщик рациона
- `vet-booking-client/` — запись на консультацию ветеринара: клиент (точки входа,
  визард записи, личный кабинет)
- `vet-booking-vet/` — запись на консультацию ветеринара: кабинет ветеринара
  (расписание, услуги, записи)
- `vet-booking-admin/` — запись на консультацию ветеринара: админка сайта (услуги,
  ветеринары, записи и оплаты, выплаты)

## Как обновить черновик

Заменить файл в соответствующей подпапке (`index.html`) и запушить в `main` —
GitHub Pages пересоберёт страницу автоматически за 1-2 минуты.
